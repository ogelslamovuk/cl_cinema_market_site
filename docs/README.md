- [Архив QA](reviews/README.md)

`reviews/` содержит исторические отчёты и скриншоты конкретных версий,
а не временные браузерные профили. Их выводы относятся к указанным там
коммитам; они не заменяют проверку текущего production. В архиве также
есть явно обозначенные синтетические состояния — это не реальные инциденты.

При уборке 26.10.2026 архив перенесён из `review-evidence/` в `docs/reviews/`.
Исторические манифесты сохранены без переписывания: их старый префикс
соответствует новому каталогу. Ссылки на исходные commit SHA по-прежнему
ведут к оригинальным версиям доказательств.
