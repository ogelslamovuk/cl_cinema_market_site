# Аналитика кинорынка Беларуси: ожидаемый результат

## Пользователи

- руководство;
- заказчик продукта;
- коммерческий блок Silver Screen / mooon.

## Главная задача

Ежедневно показывать долю Silver Screen в кинопрокате Беларуси по проданным
билетам и кассе, а затем использовать накопленную базу для решений по
расписанию и репертуару.

Рабочее определение рынка:

```text
все кинотеатры ByCard / R-KOM / 24afisha + Silver Screen = рынок Беларуси
```

## География и время

- страна;
- область;
- город;
- кинотеатр;
- календарный день;
- прокатная неделя с четверга по среду;
- день недели и время начала сеанса.

Timezone продукта: `Europe/Minsk`.

## Основные показатели

- проданные билеты рынка;
- проданные билеты Silver Screen;
- доля Silver Screen по билетам;
- касса рынка по номиналу;
- касса Silver Screen;
- доля Silver Screen по кассе;
- средняя цена билета;
- количество сеансов;
- загрузка;
- точность и полнота сбора.

Проданные билеты принимаются как посещаемость с допустимой рыночной погрешностью.

## Обязательный разрез по фильмам

Для каждого фильма показываются:

- билеты и касса всего рынка;
- билеты и касса Silver Screen;
- остальные кинотеатры;
- доля Silver Screen внутри фильма;
- доля фильма в общем рынке;
- динамика по дням, городам и времени сеанса.

Связь фильмов ByCard и Silver Screen на первом этапе выполняется по точному
названию. Несопоставленные названия выводятся отдельным quality report.

## Качество данных

Точные данные и оценки никогда не смешиваются без маркировки:

- `exact_api_sales` — API вернул точные количество и сумму;
- `availability_estimate` — оценка по недоступным местам;
- `general_admission_unverified` — безместная схема ещё не валидирована;
- `closed_before_capture` — окно сбора потеряно;
- `capture_failed` — техническая ошибка;
- `source_anomaly` — противоречие в данных источника.

Главный dashboard обязан показывать процент точного покрытия.

## Интерфейс

- тёмная тема;
- современная кинематографичная стилистика;
- первый экран строится вокруг доли рынка;
- фильтры по периоду, географии, кинотеатру и фильму;
- ниже располагаются фильмы, география, кинотеатры и временные разрезы;
- на первом этапе экспорт в Excel/PDF не требуется;
- разработческая версия размещается на GitHub Pages.

PDF Falcon используется только как визуальный mood reference. Элементы и
структура из него буквально не переносятся.

## LLM

LLM подключается только после появления консистентной базы. Она преобразует
вопрос пользователя в проверенную структуру метрик; SQL, вычисления и цифры
формирует детерминированный backend.
